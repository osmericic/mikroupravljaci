Na analogni izvod mikrokontrolera spojite srednji izvod potenciometra. Napišite program koji će serijskim putem na računalo svakih 100 milisekundi slati očitanje stanja analognog izvoda na koji je spojen potenciometar. Zakrećite potenciometar i pogledajte dobivena mjerenja na računalu pomoću Serial monitor alata.

SHEMA:

EKSPERIMENTALNA PLOČICA:

RJEŠENJE:

int pot = A0;                       //definiraj pot = A0

void setup() {
  Serial.begin(9600);               //inicijalizacija serijske veze
}

void loop() { 
  Serial.println(analogRead(pot));  //očitaj analogni izvod i pošalji
                                    //rezultat putem serijske veze
  delay(100);                       //čekaj 100 ms
}
