Preuzmi programski kod za Arduino

 

 

POGLAVLJE 7 - Zadatak 34:

Napišite program koji će svake sekunde putem serijske veze poslati poruku "VOLIM ARDUINO!" na računalo. Pomoću Serial monitor alata pogledajte dobivene podatke.

RJEŠENJE:

void setup() {
  Serial.begin(9600);               //inicijalizacija serijske veze
}

void loop() { 
  Serial.println("VOLIM ARDUINO!"); //pošalji putem serijske veze
  delay(1000);                      //čekam 1 s
}
